# 申込み最終確認画面の表示要件（特定商取引法12条の6）

無料お試し付きの月額課金は、2022年6月施行の改正でもっとも規制が厳しくなった形である。
**違反した表示により利用者が誤認して申し込んだ場合、申込みを取り消される**（法15条の4）。
課金が丸ごと巻き戻るため、実装に直結する要件としてここに固定する。

罰則は12条の6第1項違反で3年以下の拘禁刑または300万円以下の罰金、第2項違反で100万円以下の罰金。

## 1. 設計上の前提：Stripe Checkout をそのまま最終確認画面にしない

Stripe Checkout の画面は表示項目を細かく制御できず、下記の6項目を
「一覧性をもって」表示する要件を満たしきれない。

したがって **自サイト側に「お申込み内容の確認」画面を1枚挟み**、そこから Checkout へ遷移させる。
確認画面が法12条の6の名宛てとなる画面であり、Checkout は決済手段の入力画面と位置づける。

## 2. 表示必須の6項目

| 法定項目 | 献立くんでの内容 |
| --- | --- |
| 分量 | 期間の定めなし（1か月ごとの自動更新）であること |
| 販売価格 | 月額300円（税込） |
| 支払時期・方法 | 無料お試し期間の終了日に初回請求、以後毎月同日／クレジットカード |
| 役務の提供時期 | 申込み完了後、直ちに |
| 申込期間 | 定めがある場合のみ（キャンペーンを行うときは記載） |
| 撤回・解除に関する事項 | 解約方法、解約後の利用可能期間、返金の可否 |

## 4. 実装への要求

- **初回請求日をサーバ側で算出し、具体的な日付として埋める。**
  「5日後」という相対表現だけにしない。日付が出ていれば「いつ課金されるか知らなかった」と言われない。
- 6項目が**1画面に一覧で**収まること。アコーディオンや別ページへのリンクに逃がさない。
- 「自動的に有料プランに移行します」を、無料訴求と**同等以上の視認性**で表示する
  （フォントサイズ、コントラスト）。
- 解約方法を確認画面に**直接記載**する。リンクのみは不可。
  解約手段が限定される場合や受付時間に制限がある場合は、直接表示が明示的に必須とされている。
- ボタン文言は「無料お試しを開始する」等とし、有料契約でないと誤解させる表現を避ける。
- **無料お試し期間の終了前にリマインドを送る。** 法的義務ではないが、5日間は短く、
  通知が無いとチャージバックと苦情の原因になる。Stripe 側の設定で送信できる。
  既定が7日前になっている場合、5日のトライアルでは送信されないため必ず調整する。
- 確認画面のスクリーンショットをリポジトリに保存する。行政対応の際の証跡になる。

## 5. 禁止される表示（法12条の6第2項）

以下は「人を誤認させるような表示」として禁止される。実装レビューの観点として使う。

- 「5日間無料！」を大きく出し、自動的に有料へ移行する旨の記載が相対的に小さい
- 「初回0円」を強調し、定期契約であることを認識しにくくする
- 「いつでも解約できます」と表示しながら、実際には条件や制限がある
- 「お試し」の語で、継続的な契約であることをぼかす
- 解約の導線を、申込みの導線に比べて著しく分かりにくい場所に置く
